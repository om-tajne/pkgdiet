This package provides the deterministic `ALLOW`, `WARN`, `BLOCK`, and `UNKNOWN` evaluation logic used by the PkgDiet CLI, GitHub Actions CI gates, and MCP servers.

## Installation

```bash
npm install @pkgdiet/core
```
