# @pkgdiet/aws-adapter-prototype

This is an **AWS deployment prototype and integration design** for PkgDiet.

It **locally exercises selected PkgDiet tool calls through an API Gateway-shaped event harness**.

> **Note:** This package is a local API Gateway-shaped prototype. It is not currently a production Lambda deployment adapter and does not yet provide full MCP HTTP transport compatibility.
