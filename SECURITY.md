# Security Policy

## Supported Versions

Currently, only the latest major version of PkgDiet is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within PkgDiet, please **DO NOT** open a public issue. 
Instead, please send an email directly to the maintainers or use the GitHub Security Advisory "Report a Vulnerability" feature.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. 
If a vulnerability is accepted, we will issue a patch as quickly as possible.
