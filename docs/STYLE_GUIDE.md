# PkgDiet Interface Style Guide

## Emoji Usage
- 🥗 Brand header
- ✅ Success/ALLOW
- 🟡 Warning/WARN
- 🔴 Error/BLOCK
- 📦 Size analysis
- 💡 Recommendations

## Verdict Display
- ALLOW → 🟢 or ✅
- WARN  → 🟡
- BLOCK → 🔴

## Footer
Always include:
`🥗 Secured by PkgDiet · npx pkgdiet setup to enable AI guardrails · github.com/om-tajne/pkgdiet`

## Error Messages
Format:
🔴 Error: [Short description]
   [Context details]
   
   💡 Fix: [Actionable suggestion]
   📖 Docs: [github.com/om-tajne/pkgdiet#section]
